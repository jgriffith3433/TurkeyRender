# TurkeyRender

A fully real-time 3D animated music video, made in Unity 6000.3.7f1 (URP) and directed entirely from text.

A man watches TV. The TV watches back. The story is in `Director/STORYBOARD.md`.

The score lives in `Director/score.json` and `Director/acts/*.json`. `Director/mv.mjs` compiles it into the scene and Timeline, drives the open Unity editor, and renders. See `AGENTS.md`.

To rebuild: open the project in Unity, then run `node Director/mv.mjs build`. The scene and everything in `Assets/MusicVideo/Generated` are generated by that, so they aren't in this repo. Renders are on the Releases page.

Paid Asset Store content is included for private use only. Keep this repo private.
